# ДВОР

Уличный игровой клуб, созданный как независимый концепт. Адаптивный статический сайт: главная, движи, свои, заявка и информация о данных.

## Запуск

Любой статический сервер из этой папки, например `python -m http.server 4173`. Сборка и npm не требуются. Для GitHub Pages выбрать main / root.

## Что работает

Светлая и тёмная темы с сохранением выбора, мобильная навигация, фильтры движей, FAQ, перенос интереса в заявку, валидация, локальный черновик и его удаление. GSAP 3.15.0: вступительные таймлайны, раскрытие секций, лёгкое изменение масштаба изображения при прокрутке. Анимации учитывают prefers-reduced-motion.

## Заявки и документы

privacy.html: проект политики. consent.html: отдельный проект согласия. Оператор физлицо, реквизиты пока заглушки по просьбе владельца. Сохранение черновика не является согласием и не отправляет данные. Чекбокс согласия появляется только в режиме реального приёма.

config.js закрывает приём тремя настройками: пустой endpoint, applicationsEnabled:false, legalReady:false, версия draft. Не открывать форму до заполнения документов, проверки российской схемы хранения и серверной фиксации согласия. Старый Cloudflare Worker отключён; план запуска см. отдельно в dvor-backend/README.md. Telegram предполагается только для общих уведомлений без анкеты.

## Анимации

GSAP: маскированные заголовки, вступительный таймлайн, параллакс и масштаб изображений при нативной прокрутке, раскрытие секций, движущаяся текстовая полоса, реакции карточек и стрелок, короткий переход между внутренними страницами. Вдохновение: https://razedmods.com/ . Брендинг и ассеты оригинальные. prefers-reduced-motion отключает эффекты; модификаторы клика и внешние ссылки сохраняют обычное поведение.

## Дизайн

Новый авторский дизайн для аудитории 15-22: уличная игровая культура, типографика плаката, бетон, один лаймовый акцент. DESIGN_VARIANCE 7 (асимметрия и наклон арта), MOTION_INTENSITY 5 (анимации иерархии и прокрутки), VISUAL_DENSITY 4 (крупный текст, короткие абзацы). Это собственная эстетика, не имитация существующего дизайн-системного UI.

Иллюстрации созданы специально для проекта с imagegen, сохранены в WebP. Шрифт Oswald распространяется по SIL Open Font License, см. FONT-LICENSE.txt. GSAP: https://gsap.com/community/standard-license/

Референс сочетания стритвира и игр: https://higround.co/blogs/news/braindead-x-higround-lookbook . Чужие изображения и брендинг не использованы.

События обозначены как идеи, реальных дат, отзывов, участников и статистики сайт не выдумывает.
